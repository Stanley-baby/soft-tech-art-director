# Embedded Style Card Index

Use the images in `assets/style-cards/` as human-facing overview cards during Style Exploration. Use this index for machine-readable ingredients, fit, exclusions, and source Reference IDs. Canonical family names in this file override shortened text printed on a card.

## Usage rules

- Inspect only the cards relevant to the current product or the three recommended routes.
- Present a card to help the user recognize a direction; do not treat its collage as one composition to reproduce.
- Use the listed Reference IDs to retrieve atomic source images when the user supplies the reference library.
- If atomic source images are unavailable, use one Style Card as broad visual context and state that it is an overview reference.
- After the user selects a family, build a role-based Case Reference Set before writing the production prompt.
