# Soft Tech Visual Ingredients

## Core principle

`Softness × Computation = soft perception × precise computation.`

Use precise systems to express calculation and soft phenomena to express sensing, probability, flow, and generation. Soft Tech is not a fixed aesthetic template.

## Ingredient library

### Frosted Glass

- Meaning: context, partial visibility, layered intelligence, human/AI collaboration
- Use for: overlays, contextual panels, progressive disclosure, agent states
- Control: translucent fill, subtle background blur, hairline border, localized highlight
- Avoid: opaque milky cards, heavy shadows, thick reflections, every card becoming glass

### Diffused Gradient

- Meaning: continuous state change, flow, transformation, emergence
- Use for: ambient fields, active zones, transitions, generative backgrounds
- Control: two to four colors, broad diffusion, low-frequency movement, neutral space
- Avoid: default diagonal purple-blue gradients, full-canvas saturation, decorative color with no semantic role

### Fine Grain / Digital Noise

- Meaning: probability, information density, material presence, generative uncertainty
- Use for: large gradients and abstract surfaces that otherwise feel synthetic or empty
- Control: fine and even grain at low opacity
- Avoid: dirty compression, coarse noise, reduced text readability

### Technical Grid / Form-like Structure

- Meaning: data, parameters, APIs, structure, control, explainability
- Use for: dashboards, developer tools, agent workspaces, structured output
- Control: hairline dividers, consistent grid, metadata labels, restrained monospace
- Avoid: dense enterprise tables, excessive boxes, decorative grids with no alignment function

### Ambient Light / Localized Glow

- Meaning: activation, attention, system activity, intelligence in progress
- Use for: active nodes, generation states, transitions, focal hierarchy
- Control: directional and localized; one dominant light behavior
- Avoid: neon outlines, universal glow, cyberpunk lighting, low-contrast text

### Blurred Abstract Forms

- Meaning: latent space, data clusters, unresolved intelligence, emergent possibilities
- Use for: brand imagery, hero backgrounds, section transitions
- Control: low detail, imperfect silhouettes, depth and partial cropping
- Avoid: arbitrary 3D blobs, stock liquid shapes, forms that compete with content

### Atmospheric Color Field

- Meaning: computation as an ambient condition rather than a decorative object
- Use for: calm AI services, assistant surfaces, product framing, quiet brand systems
- Control: broad diffusion, no hard edges, clear neutral foreground, restrained type
- Avoid: rainbow overload, gradient text, full-screen saturation, low-contrast copy

### Dark Atmospheric Field / Shadow Gradient

- Meaning: hidden infrastructure, uncertainty, continuous monitoring, signals emerging from noise
- Use for: health metrics, sports data, risk, observability, agent status
- Control: near-black foundation, selective chromatic falloff, one luminance hierarchy
- Avoid: cyberpunk neon, universal outer glow, game HUD decoration

### Abstract Fluid Forms / Organic Volume

- Meaning: generation, fusion, multimodal transformation, living computation
- Use for: media AI, sound, video, creative systems, model identity
- Control: imperfect silhouettes, soft depth, partial crop, coherent motion behavior
- Avoid: stock 3D blobs, unrelated sculpture, too many competing forms

### Atmospheric Photography / Layered Image Collage

- Meaning: memory, place, culture, emotion, human context, intelligent narration
- Use for: discovery, travel, recommendation, personal memory, cultural products
- Control: cinematic color grade, editorial crop, one narrative focal point, minimal interface framing
- Avoid: generic lifestyle stock, illegible text on busy images, decorative collage without story

### Traces / Signals / Paths

- Meaning: orchestration, matchmaking, reasoning trails, progress, causality
- Use for: agents, workflows, recommendations, explainability
- Control: a small number of meaningful paths with states or labels
- Avoid: spaghetti diagrams and decorative connector lines

### Luminous Data Signals / Warped Modular Cards

- Meaning: active, changing, or anomalous data within a continuously sensing system
- Use for: dark monitoring interfaces and immersive data dashboards
- Control: light only meaningful states; preserve numeric legibility; use distortion as spatial hierarchy
- Avoid: lighting every card, excessive perspective, soft shapes that obscure data accuracy

## Compact recipe patterns

Use [style-taxonomy.md](style-taxonomy.md) for named Style Families. Use the recipes below only as small ingredient combinations.

### Structured Intelligence

Technical Grid + Frosted Layers + Localized Light

Use for enterprise AI, APIs, agent dashboards, analytics, and explainable systems.

### Generative Perception

Diffused Gradient + Fine Grain + Abstract Forms

Use for multimodal understanding, media intelligence, creative tools, and model branding.

### Human-AI Collaboration

Frosted Layers + Traces + Warm Ambient Light

Use for feedback loops, preference learning, assisted decision-making, and handoffs.

### Quiet Intelligence

Editorial whitespace + Technical labels + one subtle gradient field

Use for premium productivity products and interfaces where content should dominate.

## Selection rule

Choose the smallest recipe that expresses the product. Keep at least one system element and one perceptual element. Name the function of every selected ingredient.
