# Soft Tech Style Taxonomy

Use this as a recommendation tree, not as a claim that these are universally standardized design-history terms. `Soft Tech` is the umbrella language: soft perception combined with precise computation. The families below are named reusable directions within that language.

Treat names as working art-direction language rather than universal design-history categories. The core tree below is validated by the current reference library. Add a new family only when at least five coherent references share a product metaphor, not merely one visual effect.

## Decision tree

```text
SOFT TECH / 柔性科技
│
├── PERCEPTUAL / GENERATIVE / 感知与生成
│   ├── Quiet Intelligence / 静默智能
│   ├── Generative Perception / 生成式感知
│   └── Quiet Gradient Intelligence / 静谧渐变智能
│
├── HUMAN / EMOTIONAL / 人本与情感
│   └── Warm Human AI / 温感人本智能
│
├── SYSTEM / STRUCTURED / 系统与结构
│   └── Structured Intelligence / 结构化智能
│
├── SPATIAL / RELATIONAL / 空间与关系
│   ├── Signal Field / 信号场
│   └── Dark Signal Intelligence / 暗场信号智能
│
└── EDITORIAL / CULTURAL / 编辑与文化
    └── Poetic Intelligence / 诗性智能
```

## Branch questions

Use product needs to choose an initial branch:

1. Does intelligence need to feel calm, fluid, generative, or atmospheric? Start with `Perceptual / Generative`.
2. Is the experience primarily about being understood, supported, coached, or represented? Start with `Human / Emotional`.
3. Is it about control, explainability, efficiency, or complex operations? Start with `System / Structured`.
4. Is it about relationships, monitoring, orchestration, environments, or hidden signals? Start with `Spatial / Relational`.
5. Is cultural taste, memory, place, content, or narrative the differentiator? Start with `Editorial / Cultural`.

The result may use a secondary family, but recommend one primary family first.

## Style Families

### Quiet Intelligence

- Core idea: Intelligence recedes so content and decisions feel calm and obvious.
- Best for: focused productivity, personal knowledge, lightweight assistants, premium content tools.
- Primary ingredients: Editorial Whitespace, Fine Grain, Monospaced Metadata, restrained Modular Cards.
- Risk: becoming generic minimal SaaS or feeling too passive.

### Generative Perception

- Core idea: Information behaves like fluid, light, diffusion, or a living generative field.
- Best for: multimodal understanding, media intelligence, creative tools, model branding, adaptive systems.
- Primary ingredients: Abstract Fluid Forms, Diffused Gradient, Fine Grain, Soft Motion Blur, Spectral Color Shift.
- Risk: decorative abstraction that does not explain the product.

### Quiet Gradient Intelligence

- Core idea: Complex computation remains in the background while the foreground stays calm, legible, and composed.
- Best for: AI services, assistants, premium productivity, customer agents, brand-led enterprise products.
- Primary ingredients: Atmospheric Color Field, Diffused Gradient, Restrained Typography, Editorial Whitespace, Fine Grain.
- Risk: using a fashionable gradient without a distinct product metaphor.

### Warm Human AI

- Core idea: AI feels attentive, personal, and emotionally available rather than mechanical.
- Best for: coaching, companions, health/wellness, preference learning, human-in-the-loop tools.
- Primary ingredients: Photographic Layer, Localized Glow, Frosted Layer, Diffused Gradient, Soft Motion Blur.
- Risk: losing professional credibility or becoming lifestyle decoration.

### Structured Intelligence

- Core idea: Intelligence is visible as an organized, configurable, explainable system.
- Best for: agent workspaces, enterprise AI, APIs, analysis, workflows, operational tools.
- Primary ingredients: Technical Grid, Dense Data Fields, Monospaced Metadata, Modular Cards, selective Frosted Layer.
- Risk: reverting to a dense CRM or traditional enterprise dashboard.

### Signal Field

- Core idea: Meaning emerges as signals gather, connect, and form interpretable relationships.
- Best for: matchmaking, recommendations, agent orchestration, knowledge relationships, explainability.
- Primary ingredients: Relationship Traces, Localized Glow, Technical Grid, Monospaced Metadata, Asymmetric Composition.
- Risk: decorative nodes, spaghetti connections, or an unreadable graph.

### Dark Signal Intelligence

- Core idea: The system recedes into darkness while active, changing, or anomalous data appears as light.
- Best for: monitoring, health data, sports analysis, risk systems, real-time operations, agent status panels.
- Primary ingredients: Dark Atmospheric Field, Shadow Gradient, Luminous Data Signals, Warped Modular Cards, Technical Italic Typography.
- Risk: becoming cyberpunk, game HUD, or generic dark SaaS.

### Poetic Intelligence

- Core idea: AI acts as an intelligent narrator that understands memory, culture, emotion, and place.
- Best for: travel, discovery, cultural curation, personal memory, narrative recommendations, premium consumer AI.
- Primary ingredients: Atmospheric Photography, Display Serif Typography, Layered Image Collage, Cinematic Color Grading, Minimal Interface Framing.
- Risk: beautiful cultural direction with weak product comprehension or unusable controls.

## Adjacent variants

Use these as secondary labels or boundary cases unless a product and reference set clearly justify promotion to a core family:

- `Technical Minimalism`: precision, grid, restraint, technical confidence.
- `Neo Utility`: functional conventions made direct, bold, and visibly constructed.
- `Editorial Tech`: technology framed through strong editorial voice and composition.
- `Spatial Intelligence`: intelligence acting within scenes, places, layers, or three-dimensional context.
- `Organic Computation`: biological growth and living-system metaphors; usually a Generative Perception variant.

## Ingredient-selection constraints

- Include no ingredient without naming its function.
- Do not apply Frosted Layer to every container.
- Do not use Localized Glow as a substitute for hierarchy.
- Do not use Dense Data Fields on marketing surfaces by default.
- Keep Relationship Traces limited and meaningful.
- Separate marketing expression from operational product density.

## Evaluation questions for taxonomy review

For every family ask:

1. Is the name clear and memorable without pretending to be an established historical term?
2. Is it meaningfully different from neighboring families?
3. Can a non-designer recognize it from five reference images?
4. Does it apply to both a visual keyframe and an implementable interface?
5. Are its primary ingredients necessary, or merely fashionable?
6. What product types should not use it?
